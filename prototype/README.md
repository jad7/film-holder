# First working film-holder prototype

- `film-holder.sc`: SolidCraft holder assembly, archived from `experiment-pad-gate-v01/v11-fabric-pad/ASSEMBLY-DRAFT.sc`.
- `spool-ball-prototype.sc`: side magazine prototype, saved from the open SolidCraft document on 2026-11-12.
- `../filament-straightener/filament-straightener-v02.sc`: experimental filament straightener.

The user has scanned several rolls with the holder. Known issues: curled film catches at the pad frame, the first frames are difficult to advance before the take-up spool engages, and the cover is awkward to remove with the magazines attached. The light window is intentionally retained in this version. The assembly has three pre-existing feature-history errors (Chamfer1, Chamfer2 and Rail_Positive_Upper_M2_Flathead); this archive does not assert that all parts or tolerances are verified.
